# Kirameku 博客 + Vercel AI SDK - 产品需求文档 (PRD)

## 一、项目概述

### 1.1 项目背景
Kirameku 是一个高颜值的前后端分离全栈博客项目，采用毛玻璃风格 UI，具备文章系统、说说、照片墙、音乐播放器、时光河流等丰富功能。本项目在 Kirameku 的基础上，集成 Vercel AI SDK，打造一个具备 AI Agent 能力的智能博客系统。

### 1.2 核心目标
- **AI Agent 对话**：内嵌 AI Agent，可与用户自然对话
- **博客知识库**：AI 深度熟悉博客内容，能基于博客内容回答问题（RAG 技术）
- **内容编辑能力**：AI 可对博客内容进行编辑（草稿模式，不影响稳定性）
- **多模型支持**：支持用户自定义 AI 供应商，配置 API Key 即可使用
- **免费部署**：方便免费部署，适合学生党

### 1.3 适用人群
- 想搭建个人博客的开发者
- 对 AI Agent 技术感兴趣的学习者
- 预算有限的学生党
- 喜欢折腾、追求高颜值的技术爱好者

## 二、功能需求

### 2.1 核心功能清单

| 功能 | 优先级 | 说明 |
|------|--------|------|
| AI 对话聊天 | P0 | 使用 Vercel AI SDK + useChat Hook 实现 |
| 流式输出 | P0 | streamText + 前端流式渲染，打字机效果 |
| RAG 知识库 | P0 | pgvector + 向量检索 + 上下文注入 |
| 工具调用 | P0 | Vercel AI SDK Tool Calling，搜索文章、创建草稿等 |
| 多模型支持 | P1 | 用户配置 + 动态切换模型 |
| Agent 自主规划 | P1 | AI SDK Agent Runtime，多轮工具链式调用 |
| 管理后台 AI 配置 | P1 | 可视化配置 AI 供应商、API Key、模型等 |

### 2.2 AI 聊天功能
- **基础聊天**：用户可与 AI 进行自然对话
- **上下文记忆**：保持对话历史，支持多轮对话
- **流式输出**：打字机效果，实时显示 AI 回复

### 2.3 RAG 知识库功能
- **文章向量化**：文章发布时自动生成向量并存入 pgvector
- **智能检索**：用户提问时检索最相关的 N 篇文章
- **上下文注入**：将检索到的文章内容作为上下文喂给 AI
- **精准回答**：AI 基于博客内容回答问题，不胡说八道

### 2.4 工具调用功能
- **只读工具**（AI 自由调用）：
  - `searchPosts`：搜索博客文章
  - `getPost`：获取文章详情
  - `getTags`：获取所有标签
  - `getStats`：获取博客统计数据
- **写入工具**（需用户确认）：
  - `createPostDraft`：创建文章草稿（草稿模式，需审核）
  - `updatePost`：修改文章内容（需审核）

### 2.5 用户配置管理
- AI 供应商选择（DeepSeek / OpenAI / 通义千问...）
- API Key 配置
- 默认模型选择
- 系统提示词自定义
- 温度参数调节

## 三、非功能需求

### 3.1 性能要求
- 聊天 API 响应时间 < 2s（流式输出首字延迟）
- RAG 检索响应时间 < 500ms
- 前端页面加载时间 < 3s

### 3.2 安全要求
- API Key 加密存储
- 写入工具需用户确认
- 所有 AI 编辑操作记录日志

### 3.3 成本要求
- 部署成本：0 元（全用免费额度）
- AI API 成本：< 5 元/月（个人用量）

### 4.2 技术栈
| 层 | 技术 | 说明 |
|---|------|------|
| 前端 | Next.js 14+ / React 18+ / Tailwind CSS / Framer Motion | 博客前端 + AI API 层 |

## 五、开发阶段

### 第三阶段：工具调用
- 定义基础工具
- 在聊天 API 中启用工具调用
- 实现创建文章草稿工具
- 添加工具执行审批机制

### 第四阶段：用户配置管理
- 设计配置表结构
- 实现配置 API
- 管理后台配置页面
- 动态切换模型
